MON — brand sheet

All marks are true vector, drawn from real font outlines with no font dependency. Regenerate with python3 scripts/build-logo-block.py — never hand-edit the SVGs.

Primary — full lockup

The block mark with its tagline. For print, covers and any application wide enough to read the tagline.

On navy the solid block would disappear, so the reversed cut draws it as a gold outline. Same silhouette, no navy-on-navy void.

Compact — no tagline

Used by the site header, favicons and avatars. At ~31px the tagline renders about 4px tall: present but unreadable, which is worse than absent.

Size test — does it survive small?

Palette

gold #C89D5B

gold-deep #8A6A34

ink #253044

grey #5B616B

stone #E9E6DF

Gold is a dark-ground colour. On paper it measures 2.30:1 — below every WCAG floor. Small gold-toned text on light uses gold-deep (4.6:1).
